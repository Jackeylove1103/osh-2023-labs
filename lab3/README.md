## 总体设计

完成内容如下：

* 必做的所有部分
* 选做：线程池

设计思路介绍：

* 改进parse_request函数使之可以按照空格和换行逐个读取，从而实现对返回头的检测，例如GET，path，HTTP1.0，host地址之类的参量，但由于siege采用http1.1，故对http不做处理，使用全局变量flag用来标志返回状态**200**，**404**，**500**
* 对于handle_clnt,首先利用path来确定返回码，首先进行fopen获取fd来判断是否找到，再根据C库来判断是否为目录或者跳出了目录，同时置flag。由于read可能无法将文件一次读取完，故改用fread和ftell等文件函数来获取文件大小，从而利用malloc动态开辟空间，来保证一次可以写入完全部文件内容。
* 对于线程池及并发，实现线程池即可实现并发，故定义任务队列与线程池结构体，通过编写初始化线程池函数thread_pool_init，向线程池中添加任务函数add，从线程池中获取任务以执行函数get完成了线程池及并发的添加。

主要技术:

* C库函数对于文件的处理
* C库函数对于线程的处理，大体同实验文档
